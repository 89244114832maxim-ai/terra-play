# Дизайн публичной витрины «Терры»

## Назначение

`index.html` знакомит с сеттингом России 2136 года, показывает доступные механики, кадры и трейлеры и ведёт к игре либо архиву. Тон — атмосферный, мрачный, с тёплым акцентом света. Используются существующие игровые кадры и материалы проекта; концепты и обещания не выдаются за доступную сборку.

Страница работает как статический сайт в подпапке GitHub Pages. Базовое содержимое и ссылки доступны без JavaScript. Отдельного этапа сборки, внешних шрифтов, аналитики и библиотек для витрины нет.

## Контракты

### Публичные маршруты и источники

- `play/` — публичная браузерная игра. Изменения витрины не пересобирают и не перезаписывают `play/index.html`.
- `credits.html` — авторы и лицензии. Повторное использование существующих материалов сохраняет их атрибуцию.
- `https://github.com/89244114832maxim-ai/terra-play/releases/latest` — постоянная ссылка на архив выпуска; она остаётся рабочей при недоступности API.
- `assets/site.js` может запросить `/repos/89244114832maxim-ai/terra-play/releases/latest` у публичного GitHub API с тайм-аутом 3 секунды. Вставляются только текстовые номер, дата, название и размер ZIP; тело релиза не исполняется и не вставляется как HTML. Ссылки принимаются только для HTTPS-страниц releases этого репозитория.
- Метаданные относятся к архиву GitHub Release. Они не подтверждают совпадение его версии с развёрнутым `play/`.
- Утверждения о доступных механиках сверяются с публичной игрой и релизами. Незавершённые PR и внутренние планы не объявляются выпущенными.

### HTML, CSS и JavaScript

- `assets/site.css` и `assets/site.js` обслуживают только витрину. Они не создают `window.TERRA_*`, не обращаются к сохранениям игры и не изменяют её интерфейсы.
- `html.js` включает поведение мобильного меню; без него ссылки навигации видны. `#site-nav`, `[data-menu-toggle]` и `[data-menu]` связаны через `aria-controls`, `aria-expanded` и класс `.menu-open`.
- `html[data-motion="on|off"]` управляет эффектами; `data-page-hidden="true|false"` приостанавливает CSS-анимации в скрытой вкладке. По умолчанию в разметке движение выключено. `#motion-toggle` сохраняет только отдельное предпочтение `terra-showcase-motion`; `prefers-reduced-motion` и `saveData` имеют приоритет.
- `[data-reveal]` видны без JS. Класс `.reveal-enabled` добавляется только при подключённом IntersectionObserver; `.is-visible` оставляет элемент открытым после появления.
- Вкладки `.scene-tab[data-scene]` соответствуют `#scene-camp`, `#scene-combat`, `#scene-world`. Скрипт устанавливает `hidden`, `aria-selected` и `tabindex`; без скрипта все три раздела доступны.
- Досье использует `.dossier-track[data-sequence][data-frames][data-columns]`, `#moloh-still` и `#moloh-canvas`. Атлас содержит 24 кадра 512×640 в 6 колонках. Он загружается только возле секции при ширине от 960 px, точном указателе, разрешённой анимации и отсутствии экономии трафика. При ошибке остаётся неподвижное изображение. Это визуализация модели, а не дополнительный игровой 3D-движок.
- `[data-gallery]` — обычные ссылки на изображения. При поддержке native dialog они открываются в `#gallery-dialog`, с кнопками, стрелками клавиатуры, Escape и возвратом фокуса.
- `[data-trailer-open]` — обычные ссылки на MP4. Скрипт назначает `src` для `#trailer-video` только после открытия `#trailer-dialog`; фоновый автозапуск отсутствует. Закрытие останавливает и освобождает видео.

## Визуальные ограничения

Графитовый фон, тёплый светлый текст, сдержанный зелёный и янтарный акценты. Крупная типографика, игровые изображения, тонкие линии полевого досье. Эффекты поддерживают атмосферу: лёгкий параллакс, туман, появление секций и поворот Молоха при прокрутке. На мобильных экранах остаётся облегчённое представление. Информация и действия должны сохраняться при выключенной анимации и недоступном GitHub API.
