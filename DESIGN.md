# Дизайн публичной витрины «Терры»

## Назначение

`index.html` знакомит с сеттингом России 2136 года, с первого экрана показывает сюжетный трейлер, затем механики, кадры и боссов и ведёт к игре либо архиву. Тон — атмосферный, мрачный, с тёплым акцентом света. Используются существующие игровые кадры и материалы проекта; концепты и обещания не выдаются за доступную сборку.

Страница работает как статический сайт в подпапке GitHub Pages. Базовое содержимое и ссылки доступны без JavaScript. Отдельного этапа сборки, внешних шрифтов, аналитики и библиотек для витрины нет.

## Контракты

### Публичные маршруты и источники

- `play/` — публичная браузерная игра. Изменения витрины не пересобирают и не перезаписывают `play/index.html`.
- `credits.html` — авторы и лицензии. Повторное использование существующих материалов сохраняет их атрибуцию.
- `https://github.com/89244114832maxim-ai/terra-play/releases/latest` — постоянная ссылка на архив выпуска; она остаётся рабочей при недоступности API.
- Страница не обращается к GitHub API; «Скачать» ведёт по постоянной ссылке на последний релиз.
- Утверждения о доступных механиках сверяются с публичной игрой и релизами. Незавершённые PR и внутренние планы не объявляются выпущенными.

### HTML, CSS и JavaScript

Оформление и скрипт встроены в `index.html` (стиль первой версии с трейлерами, PR #1, коммит `3301b72`). Скрипт обслуживает только витрину: не создаёт `window.TERRA_*`, не обращается к сохранениям игры и не изменяет её интерфейсы.

- Ролики — внешние файлы `assets/media/terra_trailer1.mp4` и `terra_trailer2.mp4` с постерами `poster1.jpg`/`poster2.jpg`; в HTML они не встраиваются. Источник хранится в `data-src` и назначается скриптом.
- `#heroVid` — сюжетный трейлер в рамке телефона на первом экране. Он запускается без звука и только пока первый экран виден; размытый фон рисуется из кадров ролика в `#heroBlur`. `#featVid` получает источник при приближении к секции «Что тебя ждёт» и играет, пока виден. Кнопки звука и паузы у каждого ролика; включение звука у одного выключает звук у другого.
- `prefers-reduced-motion` и `saveData`: автозапуск отключён, MP4 не запрашивается до нажатия «Смотреть».
- Без JavaScript ролики не загружаются; вместо кнопок управления видна прямая ссылка «Смотреть трейлер» на MP4. Блоки `.rv` видны: скрывающая анимация действует только при `html.rv-on`, который ставится в `<head>` при наличии IntersectionObserver.
- `html.js` ставится в `<head>`. На ширине до 980 px `#menuBtn` открывает `#site-menu` (`aria-controls`, `aria-expanded`, класс `nav.menu-open`, Escape возвращает фокус). Без JS кнопка скрыта, а ссылки разделов видны строкой под логотипом.
- `[data-lb]` — обычные ссылки на изображения; скрипт открывает их в просмотрщике `#lb` со стрелками, Escape и свайпом.

## Визуальные ограничения

Тёмный тёплый фон, янтарный и ржавый акценты со свечением, лёгкий зерновой шум. Крупная типографика, ролик в рамке телефона, игровые кадры. Эффекты: размытый фон из трейлера, появление секций при прокрутке. На мобильных экранах остаётся облегчённое представление. Информация и действия должны сохраняться при выключенной анимации и недоступном GitHub API.
