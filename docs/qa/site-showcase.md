# Проверка витрины — PR #5

Дата: 28 октября 2026 года. Ветка: `dot/site-showcase`. В неё включён актуальный `main` (`c7cb1cd`) с готовой игрой и упаковкой выпуска. Изменения витрины не меняют игровой bundle.

## Проверено

- `node --check assets/site.js` и `git diff --check` — без ошибок. Локальные ссылки, изображения, шрифты и ссылки на секции существуют; дублирующихся ID нет.
- Реальный Chromium 130 через Playwright, локальный HTTP-сервер: JavaScript `pageerror=[]`, ошибок загрузки локальных ресурсов нет.
- Визуально просмотрены первый экран на компьютере и телефоне, лагерь, мир, галерея и схема связи. Галерея использует существующие изображения в двух разрешениях для чётких экранов.
- Desktop 1440×1000, телефон 412×915 и 915×412: горизонтального переполнения нет. Дополнительно проверена ширина 320 px и мобильная навигация 390 px.
- Вкладки переключаются мышью и стрелками клавиатуры; `aria-selected`, фокус и видимая панель меняются согласованно.
- Галерея: открытие, следующий кадр стрелкой, Escape, возврат фокуса к исходной ссылке. Мобильное меню: открытие, `aria-expanded`, Escape и возврат фокуса.
- Трейлер: назначение источника только по действию пользователя, открытие плеера, удаление источника и возврат фокуса после закрытия. До открытия MP4 не запрашивается.
- Досье: на desktop один запрос атласа только при приближении к секции; после первого кадра включается canvas. При отключении движения снова видна статичная картинка, выбор сохраняется после перезагрузки.
- Mobile, `prefers-reduced-motion`, `saveData`, отсутствие JS: **0 запросов атласа**, **0 запросов MP4**. На телефоне остаются только лёгкие CSS-эффекты при разрешённой анимации.
- Без JS видны все три описания механик и навигация, доступны прямые ссылки на изображения, трейлеры, игру и релиз.
- Успешное обновление метаданных проверено на сохранённом ответе публичного GitHub API для `build-20261027-2313`: номер, дата, ZIP 13,3 МБ и официальная ссылка. При реальном ответе API 403 страница сохраняет постоянную ссылку на последний релиз и работоспособные взаимодействия.

## Как проверить перед выпуском

1. Открыть главную страницу и кнопку «Играть»: переход в `play/`.
2. На ширине телефона открыть меню и вкладки, затем галерею и трейлер; закрыть их и проверить возврат фокуса.
3. На компьютере прокрутить досье Молоха, выключить анимацию и повторно открыть страницу.
4. Открыть страницу с уменьшением движения либо без JS: текст и основные действия должны оставаться доступными.
5. Проверить «Скачать сборку» и «Что нового»; номер архива не следует считать версией развёрнутого `play/`.
